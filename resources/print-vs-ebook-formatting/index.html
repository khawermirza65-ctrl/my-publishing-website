Print is a fixed page

A print interior has a chosen trim size, margins and page numbers. Chapter openings, headings and paragraph styles should create a consistent reading rhythm. The inside margin must allow for binding, and illustrations must be prepared for the chosen printing process.

An ebook adapts to its reader

In a reflowable ebook, readers can change text size and screen orientation. Text moves to fit the device. Avoid relying on spaces, repeated returns or a particular screen position to create the layout. Navigation and semantic heading styles matter more than fixed page numbers.

Review each format separately

A print-ready PDF does not automatically make a good ebook. Check print proofs for spacing, image reproduction and page flow. Check an EPUB on more than one screen size for chapter navigation, image placement and text resizing. Complex illustrated books may require a different approach.

Prepare a clean handover

Finish substantive editing before layout. Provide the manuscript, image files, captions, front matter and back matter. Confirm the platforms and print format before production so the final files can be prepared for the correct specifications.
