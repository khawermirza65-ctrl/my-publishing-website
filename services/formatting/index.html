Book formatting and typesetting

Print layout and EPUB formatting so your interior reads cleanly on paper and on screen.

Ask about this service

Who it is for

Authors with an edited manuscript who need print-ready and ebook files.

The problem it solves

Word files rarely export into clean books; margins, headings and page numbers need deliberate setting.

What is included

  • Interior layout at your chosen trim size
  • Chapter openings, running heads and page numbers
  • Reflowable EPUB for ebook retailers
  • Proof review before final files

What we need from you

  • Final edited manuscript
  • Trim size preference and any special elements such as tables or images
  • Front and back matter text

How it works

  1. Style and trim size decision
  2. Layout
  3. Proof review
  4. Final print PDF and EPUB

Scope boundaries: Image-heavy or highly designed interiors are scoped separately. Formatting changes after final approval may need a new scope.

Questions about this service

Is print formatting the same as ebook formatting?

No. Print uses fixed pages; ebooks reflow to the reader's screen, so each is built differently.

Can you work from a Word file?

Yes. A manuscript using consistent styles makes the process faster.
